Window Layout
=============

Save and restore window positions across Windows virtual desktops —
including an optional restore when you sign in.

Requirements
------------
  • Windows 10 or 11 (64-bit)
  • PowerShell 5.1 (built-in) or PowerShell 7 (optional)

After setup
-----------
  1. Open Start Menu → Window Layout
  2. Arrange your windows how you like them
  3. In the app: save layout → test restore → turn on sign-in restore (step 3)

Sign-in restore and PowerShell 7 are optional and configured in the app,
not in this installer.
